| 산출물 | 파일 | 설명 |
| :--- | :--- | :--- |

## 핵심 시나리오 — 같은 부품이 두 품목으로 쪼개지는 문제

| 날짜 | 품번(원본) | 수량 |
| :---: | :---: | ---: |
| 1/05 | `KJ-H2201` | 40 |
| 1/12 | `KJH2201` (하이픈 누락) | 35 |
| 1/20 | `KJ-H2201` | 50 |
| 1/27 | `KJH2201` (하이픈 누락) | 22 |

- 기준 없이 집계: `KJ-H2201` **90** + `KJH2201` **57** → 서로 다른 부품 2개 ❌
- 표기 규칙(`^KJ-[A-Z]\d{4}$`) 적용 후: `KJ-H2201` **147** → 단일 부품 1개 ✅
- 실제 엑셀 대장 12개월 집계에서는 동일 부품 **107개**가 별도 품목으로 분리됨

## 실행 방법

빌드 없이 `docs/index.html`을 브라우저(Chrome/Edge)로 열면 됩니다. (Tailwind CSS · Lucide · Chart.js · SheetJS를 CDN으로 불러오므로 인터넷 연결 필요)

## 화면에서 해 볼 것 (완료 기준 AC-1 ~ AC-3)

1. **⚡ 기준정보 일괄 정규화 (Auto-Fix)** 클릭 → 스캔 레이저가 대장을 훑으며 `KJH2201 ➔ KJ-H2201`, `26/1/12 ➔ 2026-01-12`로 셀이 플립 전환되고, 우측 비교 카드의 막대 2개(90/57)가 하나(147)로 합쳐짐
2. 접수 폼에 `KJH2201`, `26/1/12`, 발주처 `한결방산시스템`/`구미정밀공업` 입력 → 주황 교정 추천, ISO 변환, `체계업체`/`1차 협력사` 배지
3. 상단 권한을 **박승인 · 승인 책임자**로 전환 → **책임자 승인 확정** → 파티클 + 토스트, ERROR·중복 3건을 뺀 11건 Approved, 감사 로그에 처리자·초 단위 시각 기록
4. **기준정보 마스터** 패널에서 품번 12종·발주처 8곳 검색, 책임자는 품번·발주처 추가 가능 (추가 즉시 전체 재검증)
5. 라이트/다크 테마 전환, CSV/엑셀 업로드(샘플 CSV 제공), 감사 로그 CSV 내보내기
