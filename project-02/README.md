# Project 02 — KIT 공강 산책 코스

금오공과대학교(KIT) 학생이 **출발 건물**, **다음 수업 건물**, **남은 공강 시간**, 그리고 **날씨·계절·시간대(낮/저녁/야간)** 를 입력하면, 다음 수업에 늦지 않고 다녀올 수 있는 교내 산책 코스 TOP 3를 추천하는 웹 앱입니다.

- 추천 코스는 캠퍼스 안내도 위에 동선으로 그려집니다.
- 지금 계절·시간대에 볼 만한 구간(벚꽃길·단풍길·야간 조명 코스, 여름 분수대)도 지도에 강조됩니다.
- 상황에 맞는 **실제 캠퍼스 사진**으로 코스를 미리 볼 수 있습니다.
- 산책 타이머가 언제 돌아가야 하는지 알려 줍니다.

**순수 HTML / CSS / JavaScript**로 만들었습니다. 빌드 과정, 백엔드, API 키가 필요 없습니다. 진입점은 [`index.html`](./index.html)이고, 모든 리소스를 **상대 경로**로 참조하므로 GitHub Pages(`hahmjason/docs`)에서도, 파일을 직접 열어도 그대로 동작합니다.

### ② 처리 (추천 · 경로 계산 · 사진 매칭)

1. **도보 그래프**
   - 노드: 21개 지점, 도서관 앞 분수대, 숲길 쉼터, 교차점 14개
   - 엣지: 56개. 각 엣지에는 다음 속성이 있습니다.
     - 거리(m) = 픽셀 거리 × 추정 축척 2.6m
     - 난이도: 평지 ×1.0 · 오르막 ×1.2 · 계단 ×1.3
     - 환경 속성: 개방·그늘·처마/실내 인접·수변·숲·흙길·**야간 조명(lit)**
     - 특화 태그: `cherry` · `maple` · `nightLit`
2. **프로필 합성** — `composeProfile(날씨, 계절, 시간대)`
   - 세 프로필의 가중치를 합산합니다.
   - 흙길 제외 같은 제외 조건은 하나라도 해당하면 적용합니다(OR).
   - 장거리 기준은 셋 중 더 엄격한 값을 씁니다.
   - 보행 계수는 곱합니다(비 1.1 · 눈 1.25 · 야간 1.05).
3. **경로 탐색**
   - 다익스트라로 찾으며, 구간 비용은 `길이 × 경사 × 환경 배율(0.7~1.8) × 특화 구간 배율(최소 0.6)`입니다.
   - 그래서 봄에는 벚꽃길, 야간에는 조명 구간이 실제로 경로에 더 잘 선택됩니다.
4. **후보 코스**
   - `[출발] → (경유 스팟 0~3곳의 모든 순열) → [다음 수업 건물]`을 만듭니다.
   - 계절·시간대 전용 스팟은 해당 상황에서만 후보가 됩니다. 오름관 벚꽃길·본관 벚꽃은 봄에만, 글로벌관 하늘마당 야경은 저녁·야간에만 들어갑니다.
5. **공강 여유 판정** — `여유 = 남은 시간 − (걷기 + 경유 휴식 + 준비 버퍼)`

   | 판정 | 여유 | 처리 |
   | :--- | :--- | :--- |
   | `SAFE` | 3분 이상 | 우선 추천 |
   | `TIGHT` | 0~3분 | 추천하되 −8점 |
   | `OVER` | 0분 미만 | 제외. 바로 이동해도 OVER면 최단 경로와 경고만 표시 |

6. **점수**: `50 + 환경 점수×4 + 상황(날씨·계절·시간대) 스팟 점수 + 특화 구간 점수 + 테마 점수 + 시간 활용도 − 장거리 − 중복 구간 − 복잡도 − 판정 감점`
   - 특화 구간 점수는 해당 구간을 150m 이상 걸으면 100% 반영됩니다.
   - 시간 활용도는 쓸 수 있는 시간의 75%를 산책에 쓸 때 가장 높습니다.
   - TOP 3는 경유 스팟 구성이 서로 다르게 고릅니다.
7. **복귀 출발 권장 시각** = 산책 시작 + (남은 시간 − 버퍼 − 마지막 경유지에서 다음 수업 건물까지 걷는 시간)

#### 상황별 사진 매칭기 `selectContextualPhoto({ focus, stops, season, time, weather })`

입력이 같으면 항상 같은 결과를 내는 순수 함수입니다. 11장 중 대표 사진(`hero`)과 관련 갤러리(`gallery`)를 고릅니다.

- **지점 일치**: 고른 지점 +10, 코스 경유 스팟 +8(첫 경유지는 +2 추가), 출발·도착 +3
- **계절**: 일치 +4, `all` +1, 불일치 −6
- **시간대**: 일치 +4, `all` +1, 불일치 −5
- **분수대 규칙**: 여름에는 `fountainActive: true` 사진만, 다른 계절에는 `false` 사진만 씁니다. 그래서 `분수대 작동 모습` ↔ `분수대` 사진이 계절에 따라 바뀝니다.
- **선택 없음(전경 모드)**: 캠퍼스 전경 +4. 그래서 낮 → 저녁 → 야간에 따라 `KakaoTalk…webp`(전경) → `학생회관 옆 학생 소극장` → `글로벌관 옥상 야경`으로 바뀝니다. 봄밤에는 `벗꽃` 사진이 선택됩니다.

### ④ 시스템 연동 (날씨 · 시각 · 시뮬레이터)

- **Open-Meteo** (무료, API 키 불필요): 금오공대(구미시 양호동, 36.1455, 128.3932) 기준으로 조회합니다.
  - Forecast: 기온·체감온도·습도·강수량·WMO 날씨 코드·풍속과 **오늘 일출/일몰**
  - Air Quality: PM10·PM2.5
- **계절·시간대 자동 판별** (`js/context.js`)
  - 계절은 월로 정합니다(3~5 봄 · 6~8 여름 · 9~11 가을 · 12~2 겨울).
  - 시간대는 API 일몰 시각을 기준으로 정하고, 없으면 계절별 평균 일몰표를 씁니다.
    - **저녁·노을**: 일몰 60분 전 ~ 일몰 40분 후
    - **야간**: 그 뒤부터 일출 전까지
  - 1분마다 다시 판별하므로 노을 → 야간으로 바뀌면 추천도 자동으로 바뀝니다.
- **시간표 연동**: 현재 시각(또는 테스트 시각)으로 오늘 남은 첫 수업의 건물과 남은 시간을 채웁니다. 직전 수업이나 진행 중인 수업의 건물을 현재 위치로 추정합니다.
- **오프라인 폴백**: 7초 동안 응답이 없으면 3시간 안의 최근 조회값을 쓰고, 그것도 없으면 계절 기본값을 씁니다. 어느 경우에도 앱은 멈추지 않습니다.
- **통합 시뮬레이터**: 날씨·계절·시간대를 자유롭게 바꿀 수 있습니다. [모두 실시간으로]를 누르면 자동 판별로 돌아갑니다.

### ⑤ 인프라 (정적 호스팅 & 이미지 최적화)

- 빌드 도구, 프레임워크, CDN, 외부 폰트, `.env`, 유료 API 키를 쓰지 않습니다.
- 클래식 `<script>`와 상대 경로만 쓰므로 `file://`, 로컬 서버, GitHub Pages에서 똑같이 동작합니다.
- **한글·공백·괄호가 들어간 파일명**은 원본 이름을 그대로 두고 `photoUrl()`에서 `encodeURI('./' + 파일명)`로 바꿔 참조합니다. 예: `./%EA%B8%88%EC%98%A4...%EB%B2%97%EA%BD%83.jpg`. 인트로 GIF는 HTML에 미리 인코딩된 경로로 넣었습니다.
- 큰 사진(`금오공대 도서관.jpg` 7.9MB, `금오공대 벗꽃.jpg` 6.1MB 등)은 다음처럼 처리합니다.
  - 썸네일·갤러리·팝업 이미지는 `loading="lazy"`, `decoding="async"`로 필요할 때만 불러옵니다.
  - 모든 사진 영역은 `aspect-ratio`로 크기를 먼저 잡고 `object-fit: cover`로 채워, 이미지를 받는 동안 레이아웃이 흔들리지 않습니다.
