## ★ 납기회신 가능 수량 (6-C)

- **계산식:** 납기회신 가능 = 출하 가능 재고 + 입고예정 − 미출고 확정 수주
  - **출하 가능 재고:** 창고마스터 '출하 가능'=Y인 가상창고(G1-AVL)의 03_창고재고 '재고현황' 수량
  - **입고예정·미출고:** 03_창고재고의 '입고예정'·'미출고수주' 시트 수량 합계
- **제외 재고:** '출하 가능'=N인 재고(검사 대기 G1-QI · 부적합 G1-NCR · 고객 위탁 G1-CSG · 수리부속 G1-SPR)는 계산에서 빼고, 사유를 칩으로 표시합니다. 칩에 마우스를 올리면 창고마스터의 운영 기준 문구가 보입니다.
- **물리 재고 기준과 비교:** 체크하면 출하 불가 재고까지 넣은 잘못된 수치(49·19·9)와 그 차이(과대 약속)를 함께 보여줍니다.
- **검증:** 화면 값이 Python 독립 계산과 같습니다. KJ-H2201 = 42 + 20 − 46 = **16**, 제외 33(검사 대기 12 · 부적합 3 · 고객 위탁 10 · 수리부속 8).

## UI / UX

- **레이아웃:** 왼쪽 사이드바(로고 · 메뉴)와 위쪽 통합 검색, 페이지 제목 옆 조회건수로 구성했습니다. 좁은 화면에서는 메뉴가 위로 올라갑니다.
- **통합 검색 (`/` 키):** 품번 · 발주처 도면번호 · 구 개정판 · 품명 · 발주처를 한 칸에서 찾습니다. Enter를 누르면 품목 상세가 바로 열립니다.
- **품목 상세 서랍:** 그림, 표준단가, 출하검사, 납기회신 계산, 가상창고별 재고, 입고예정, 미출고 수주를 보여주고, 회신 메모를 복사할 수 있습니다. Esc로 닫습니다.
- **로고와 품목 그림:** SVG로 직접 만들었습니다. 품목 그림은 중분류별 **일러스트이며 실제 제품 사진이 아닙니다**. 실제 사진은 받으면 바꿔 넣을 수 있습니다.
- **표시 원칙:** 상태는 색과 함께 아이콘·글자(✓ · ✕ · 제외 사유)로 보여주고, 숫자는 같은 자리에 정렬합니다.

- **표기:** 정상 ✓(초록)과 오류 ✕(빨강)는 색과 함께 아이콘·글자로 표시합니다.

## ③ 수주 검증 (실습5)

엑셀을 끌어다 놓으면 브라우저 안에서만 읽고 검사합니다. 파일을 외부로 보내지 않고, 원본도 바꾸지 않습니다.

| 규칙 | 판정 | 01_수주납품대장 결과 |
| :--- | :--- | ---: |
| ① 발주처 빈 값 | 빈 칸 또는 공백만 있음 | 15 |
| ① 로트번호 빈 값 | 빈 칸 또는 공백만 있음 | 16 |
| ② 수량 0 이하 | 0, 음수. 숫자로 읽을 수 없는 값도 여기로 분류 | 11 |
| ③ 중복 | 위쪽 어느 행과 9개 항목이 원본 값 그대로 모두 같음. 처음 나온 행은 정상, 뒤 행만 오류 | 21 |
| **합계** | 한 행에 여러 위반이 있으면 위반은 각각 세고, 오류 행은 1번만 셈 | **63행** |

- **오류 목록:** 엑셀 행 번호(머리글 포함, 데이터는 2행부터), 규칙, 항목, 값, 사유. 규칙별 필터와 행 번호 검색이 있습니다. 행을 누르면 9개 항목 전체가 보이고, 중복이면 기준 행도 함께 보입니다.
- **저장:** `원본이름_정상행_1921건.xlsx`(시트 '수주납품', 원본 값과 순서 그대로)와 `원본이름_오류목록_63건.xlsx`입니다.
- **파일 확인:** 시트 이름이나 머리글 9개가 약속과 다르면, 검사하지 않고 무엇이 다른지 알려 줍니다. 완전히 빈 줄은 데이터로 세지 않습니다.
- **검증:** 화면 결과를 Python 독립 계산과 대조했습니다. 오류 63건이 행 번호·규칙까지 같고, 저장 파일의 1,921행은 원본 값과 같습니다.

## 추가 기능

- **납기회신 가능 수량(ATP):** 출하 가능 재고(G1-AVL) + 입고예정 − 미출고 확정 수주. 행을 누르면 가상창고별 재고(할당 가능/불가), 입고예정, 미출고 수주가 근거로 열립니다. 예: KJ-H2201은 42 + 20 − 46 = 16 EA입니다.
- **회신 메모 복사:** 품번, 표준단가, 출하검사, 회신 가능 수량을 한 번에 복사합니다.
- **발주처 검증:** 발주처마스터와 정확히 일치해야 '등록'으로 판정합니다. `가람 체계`, `누리테크(주)`, `한울시스템`처럼 비슷하지만 다른 표기는 '미등록'으로 판정하고, 맞는 후보를 제시합니다.
- **수주납품대장 발주처 점검:** 1,984행 중 1,969행이 일치합니다. 발주처 **공란 15행**은 엑셀 행 번호를 표시합니다(190, 390, 566 …). 미등록 이름 표기는 0행입니다.
- **검색어 표시:** 입력한 검색어를 다시 보여주고, 한글로 입력되면 한/영 전환을 안내합니다. 입력칸 글자색은 고정입니다.
