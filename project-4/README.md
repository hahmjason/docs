# Project 4: 금오정밀 품목 조회

> 견적과 납기를 회신하기 전에 엑셀을 열지 않고 품목 12종의 **표준단가**와 **출하검사 방식**을 바로 확인하는 조회 화면입니다. (기준정보 2주차 실습4·5, 품목 조회)

| 산출물 | 파일 | 설명 |
| :--- | :--- | :--- |
| 조회 화면 | [`index.html`](./index.html) | 단일 HTML입니다. 서버와 빌드가 필요 없습니다 |
| 데이터 갱신 | [`build.py`](./build.py) | 기준정보 엑셀이 바뀌면 화면 데이터를 다시 반영합니다 (원본은 읽기 전용) |

## 기능

- **목록:** 품번, 품명, 분류(대 › 중 › 소), 단위, 표준단가(원), 출하검사(전수/샘플링 배지)
- **대분류 필터:** 전체 12 / 전장 조립체 7 / 기구 부품 3 / 소모성 부품 2
- **품번 검색:** 부분 일치. 대소문자, 하이픈, 공백을 무시합니다 (`kjh2201`, `KJ H2201` → `KJ-H2201`)
- **별칭 검색:** 발주처 도면번호(`GR-HNS-01`, `HW-SB4102`)와 구 개정판 품번(`KJ-B1107A`)으로도 표준 품번을 찾고, '별칭 일치'와 그 사유를 표시합니다
- **검색어 표시:** 입력한 검색어를 표 위에 다시 보여주고, 한글이 입력되면 한/영 전환을 안내합니다

## 요구 원문에 없어서 정한 사항

| 항목 | 결정 | 근거 |
| :--- | :--- | :--- |
| 데이터 반영 | 엑셀을 스냅샷으로 떠서 화면에 넣음. 출처와 추출일(2026-11-24)을 화면에 표시 | 원문은 수정 금지. 엑셀 없이도 동작해야 함 |
| 검색 규칙 | 대소문자, 하이픈, 공백을 무시함 | 품번별칭 시트에 같은 유형의 표기 오류가 있음 |
| 별칭 검색 | 품번별칭 시트 9건을 검색에 연결함 | 견적 요청에 발주처 품번이 적혀 오는 경우를 대비함 |
| 단가 | '표준단가(원)'로 표기하고 견적가가 아니라고 명시함 | 부가세와 수량 할인 정보가 원문에 없음 |
| 출하검사 | 전수와 샘플링 배지만 표시함 | 샘플링 기준(AQL)과 검사 기간은 원문에 없어 지어내지 않음 |
| 제외 | 재고, 납기, 로트관리(12건 모두 Y), 발주처, 창고 | 요구 범위 밖이거나 구분할 의미가 없음 |
| 입력 가시성 | 입력칸 글자색을 고정하고, 검색어를 다시 표시함 | 사용자 피드백: "타이핑한 게 안 보인다" |

## 검증

- 12건, 대분류별 7/3/2건, 전수 4건과 샘플링 8건, 단가 합계 1,715,800원이 원본과 일치함
- 별칭 9개 표기가 모두 해당 표준 품번 1건으로 검색됨. 필터와 검색을 함께 써도 정상임
- 작업 전후 원본 엑셀의 해시가 같음 (원문을 수정하지 않음)

## 실행과 데이터 갱신

- 실행: `index.html`을 브라우저로 엽니다.
- 기준정보 엑셀이 바뀌었을 때 갱신: `pip install openpyxl` 후 `python build.py 02_금오정밀_기준정보.xlsx index.html`

> 기준정보는 교육용 가상 데이터입니다.
