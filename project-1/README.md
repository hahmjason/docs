# Project 1 — 동아리 매니저 (Club Manager)

동아리 운영에 필요한 **공지사항, 일정·출석, 회원 명단, 회비·장부**를 하나의 화면에서 관리할 수 있는 순수 HTML/CSS/JavaScript 웹 애플리케이션입니다.  
별도의 빌드 과정이나 프레임워크 없이 브라우저에서 바로 실행할 수 있으며, 일반 브라우저(미리보기 모드)와 `window.claude.use` 기반 데이터 연동 모드를 모두 지원합니다.

## 파일 구성

이 폴더에는 동일한 기능의 앱이 두 가지 형태로 포함되어 있습니다.

- [`club-manager.html`](./club-manager.html) — HTML, CSS, JavaScript가 한 파일에 합쳐진 **단일 파일 버전**
- [`club-manager/`](./club-manager/) — 구조별로 파일을 나눈 **분리 버전**
  - [`index.html`](./club-manager/index.html): 상단 헤더, 5개 탭 네비게이션, 모달·토스트 마크업
  - [`style.css`](./club-manager/style.css): 반응형 UI, 라이트/다크 테마(`prefers-color-scheme: dark`, `[data-theme="dark"]`) 스타일
  - [`app.js`](./club-manager/app.js): 상태 관리, 화면 렌더링, CRUD 모달, 출석/회비/장부 계산 및 데이터 계층(`realApi` / `mockApi`)

## 주요 기능

1. **홈 대시보드 (`#home`)**
   - 활동 회원 수(전체/휴면 구분), 다음 일정 D-day, 현재 학기 회비 납부율(진행률 바), 현재 잔액(수입·지출) 요약 타일 제공
   - 최근 공지사항 3건 및 다가오는 일정 3건 미리보기
2. **공지사항 (`#notices`)**
   - 카테고리(`일반`, `중요`, `행사`, `모집`) 지정 및 상단 고정(`상단 고정` / `고정 해제`) 지원
   - 공지 작성, 수정, 삭제
3. **일정·출석 (`#events`)**
   - 다가오는 일정과 지난 일정을 구분해 날짜 카드와 함께 표시
   - 일정별 출석 패널에서 회원별 **출석 / 지각 / 결석** 체크 및 `미기록 전원 출석` 일괄 처리 지원
4. **회원 명단 (`#members`)**
   - 이름·학번·학과·연락처 검색 및 역할(`전체`, `회장`, `부회장`, `총무`, `운영진`, `회원`, `휴면`) 필터
   - 회원별 출석률 및 현재 학기 회비 납부 상태 자동 표시, 회원 추가·수정·삭제
5. **회비 및 장부 관리 (`#fees`)**
   - 회원별 납부 여부(`Y` / `N`), 받은 금액 입력, 기준 금액 대비 미수금 자동 계산, `완납 처리` 버튼 제공
   - 받은 금액을 기준 회비 이상 입력하면 `Y`, `0`으로 지우면 `N`으로 자동 전환되며 개별 수동 조정도 가능
   - 회원별 회비 납부 금액은 장부 수입으로 자동 반영되며, 별도 수입·지출 기록 추가/삭제 가능
6. **동아리 설정 (`동아리 설정`)**
   - 동아리 이름, 현재 학기(예: `2026-2학기`), 1인당 회비 금액 설정

## 동작 모드 및 실행 방법

- **미리보기 모드 (일반 브라우저 / GitHub Pages)**:  
  `window.claude.use`가 없는 일반 환경에서는 내장된 `mockApi`와 `seedPreview` 데이터가 자동으로 로드되어, *"우리 동아리 (예시)"* 샘플 데이터를 기반으로 모든 화면과 기능을 즉시 테스트할 수 있습니다. (미리보기 모드의 변경 사항은 새로고침 시 초기화됩니다.)
- **실시간 연동 모드 (`window.claude.use`)**:  
  `claude.use("db")` 및 `claude.use("user")`가 제공되는 환경에서는 실시간 데이터베이스 구독 및 권한(`data.write`, `canEdit`)에 따른 읽기 전용/회비 관리 권한 제어가 동작합니다.
